# 구현 상태와 수용 기준

2026-10-13 기준. 로컬 동작 검증과 실제 소스 수집 성공을 분리한다. 원본 서비스의 10개 메뉴 역할·정적 계약을 조사했고, 로그인 브라우저로 목록·상세·필터·메뉴 연결을 읽었다. 원본에서 등록/삭제/공유/알림 발송 같은 변경은 실행하지 않았다.

## 워크스페이스

브랜드·카테고리별 워크스페이스 추가와 전환을 지원한다. 목록은 별도 레지스트리에 저장하고 기존 Fraijour DB·인증 파일은 이전하지 않고 그대로 사용한다. 새 공간은 독립 DB와 인증 파일을 사용하므로 콘텐츠·수집 대상·지표 이력·추적 조건·브랜드 사전·광고·북마크가 분리된다. 선택 공간은 URL에 남고 API 요청의 검증된 공간 ID로 전달되어 다른 탭의 선택을 덮어쓰지 않는다.

워크스페이스는 현재 개인 로컬 앱의 조사 구분이다. 팀 초대·회원별 접근 제어, 공간 간 자료 이동·복사, 공간 이름 변경·삭제는 아직 없다. 새 공간에는 Instagram 연결도 별도로 설정한다. 생성·전환·새로고침·다중 탭과 재시작 후 영속성, 기존 자료 보존, 다른 공간의 ID를 이용한 변경 차단을 테스트했다.

## 기술 기반

Express + Node SQLite, React + Vite + TypeScript. 서버가 콘텐츠와 지표 관측 이력, 계정, 폴더/메모, 추적 세트, 브랜드 별칭 사전, 수동 광고 참고를 저장한다. 검색/집계에는 동일 조건을 적용하며 알려진 지표만 합산하고 결측은 null로 유지한다.

Instagram 어댑터는 고정 Graph 호스트와 Authorization 헤더, 제한된 pagination·retry·timeout을 사용한다. 같은 계정의 동시 수집은 프로세스 내 차단한다. 자동 갱신은 기본 꺼짐이고 켠 계정만 서버 실행 중 갱신한다. 24시간 서버나 팀 서비스로 배포되지 않았다.

## 첫 수용 테스트

`수분크림 → 비교 브랜드 A → 수부지 → 작성자 → 그 계정의 탄력탱탱 등 다른 표현 → 이전 조건 복원` 흐름을 별도 합성 DB에서 브라우저 테스트한다. 브랜드는 테스트 중 명시적 사전 등록으로 연결한다. 원본에서 동일 내용의 글을 찾았다는 증거가 아니다.

추적 조건 영속성/삭제 후 콘텐츠 보존, 자사 제외, null 지표, 동기간 비교, 중복 저장, API 실패 시 데이터 보존, 인증 비노출, 출처 도메인 검증, 모바일 너비와 키보드 닫기 등을 테스트한다. 스크린샷의 테스트 자료는 운영 DB로 이동하지 않는다.

## 실제 원천 수집 검증

2026-10-13 01:34 KST에 Fraijour 공식 계정(`fraijour_official`)의 최근 100개 게시물 수집을 확인했다. 재실행 후에도 저장 100개/고유 ID 100개였다. 계정 프로필의 전체 게시물 수는 515개이고 후속 cursor가 있어 전체 이력이 아니다. 자동 갱신은 꺼져 있다.

실제 Meta 중첩 응답이 `paging.next` 없이 `paging.cursors.after`만 제공하는 것을 확인하여 cursor 기준으로 최대 4페이지를 읽도록 수정했다. 반복 cursor와 제한 도달 여부도 테스트했다. 이전 실패 시 기존 자료 보존 계약은 유지한다.

최근 1년 자사 분석은 100개, 외부 브랜드 멘션은 0개로 확인했다. 이는 **수집한 자료가 자사 글뿐이어서 외부 언급이 관측되지 않았다는 뜻**이며 시장에 외부 언급이 없다는 뜻이 아니다. Fraijour/프레쥬 별칭 사전과 외부 언급 추적 조건을 로컬에 저장했다.

빌드, 서버 테스트 21개, 브라우저 테스트 9개 통과. 이후 수집 pagination 수정과 탐색 연결 보완에 대해 서버 전체 및 관련 브라우저 테스트 2개를 다시 통과했다. 테스트 자료와 실제 수집 증거는 분리했다.

## 다음에 풀어야 할 가장 중요한 의존성

1. **직접 원천 수집의 범위**: Instagram의 미등록 계정 발견과 Meta 광고의 자동 검색에 사용할 접근 경로·권한·범위·비용을 검증한다. 빈 검색 결과와 미연결을 구분한다.
2. **실제 수집의 운영화**: 공식 계정 최초 연결·재수집은 완료했다. 다음은 토큰 만료/권한 변경, 새 게시물 갱신, 외부 계정 접근을 검증한다. 인증값을 대화/로그/문서에 넣지 않는다.
3. **발견의 출처와 최신성**: 어떤 검색에서 처음 발견했는지, 백필/증분/페이지 제한, 마지막 성공·실패·관측 시각을 콘텐츠와 연결한다.
4. **사람이 쓸 수 있는 방법**: 실제 Fraijour 원문으로 위 탐색을 수행하고, 브랜드별/계정별 표현이 제품·메시지 검토에 유용한지 확인한다.
5. **원본 화면 충실도**: 주요 경로의 화면을 나란히 검토하고 목록·상세·필터·탭·저장 동작을 맞춘다. 확장 아이디어는 별도 항목으로 유지한다.

외부 공급자가 정해지지 않은 상태에서 전역 검색·트렌드·24시간 모니터링이 완성됐다고 표시하지 않는다.
