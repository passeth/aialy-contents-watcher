# 제품 지식에서 시장 관찰로 이어지는 탐색

## 목적과 구현 순서

우리 회사는 제조사로서 제품·성분 지식이 있지만, 브랜드 마케팅의 탐색·판단 루틴이 부족하다. 캐치모먼트의 화면·기능·메뉴 연결을 기본으로 사용하면서 방법을 익힌 뒤 Fraijour에 필요한 기능을 확장한다. 기존 제품 데이터나 서버에 의존하지 않고 원천 플랫폼에서 직접 수집한다.

Instagram 소셜 콘텐츠와 Meta 광고를 우선 대상으로 삼고, 다음에 YouTube를 연결한다. 기타 커뮤니티·쇼핑몰·리뷰 소스는 현 단계 핵심 범위가 아니다. 채널 수보다 **몰랐던 언급을 발견하고 다음 질문으로 이어가는 능력**이 중요하다.

## 원본에서 확인한 연결

로그인된 화면과 [공식 가이드](https://catchmoments.ai/guide), 공개 클라이언트 코드 관찰을 함께 사용했다. 원본 자체의 효과·마케팅 성과를 검증한 것은 아니다.

- 허브는 소재를 훑는 진입점, Research는 조건별 목록·집계, 추적 관리는 저장된 수집/분류 대상, 멘션 화면은 지속 관찰, 북마크는 재사용할 레퍼런스를 모으는 공간으로 연결된다.
- [소셜 Research](https://catchmoments.ai/guide/search)의 대시보드·게시물·콘텐츠 분석은 동일 주제를 다른 관점에서 살핀다. 브랜드·표현·작성자와 관련 게시물 연결이 반복 탐색을 만든다.
- [브랜드 허브](https://catchmoments.ai/guide/brand-hub)는 소셜·광고·크리에이터 관점을 교차한다. [크리에이터 허브](https://catchmoments.ai/guide/creator-hub)의 브랜드 연관은 언급 관찰이며 유료 협업 계약의 증명이 아니다.
- [추적 관리](https://catchmoments.ai/guide/status)는 우리 브랜드, 자사 계정, 타겟 키워드/계정 세트를 구분한다. 북마크·즐겨찾기는 추적 시작과 별개다.

정확한 메뉴별 근거 수준, 지표 식, 알려지지 않은 부분은 `rea-menu-contracts.md`에 있다. 이번에 추가한 탐색 경로 표시와 ‘현재 결과에서 좁히기/키워드로 새 탐색’ 버튼은 사용자가 설명한 동작을 구현한 것으로 원본의 동일 UI가 확인됐다는 뜻이 아니다.

## 사용자가 제시한 첫 번째 흐름: 제품에서 메시지로

1. `수분크림`을 탐색한다.
2. 관련 글에 나타난 브랜드를 본다.
3. `라운드랩`을 선택해 수분크림 관련 글 안에서 해당 브랜드의 표현을 살핀다.
4. `수부지`라는 표현을 발견한다.
5. 수분크림·라운드랩 조건 안에서 좁히거나, 조건을 풀고 수부지로 새 탐색을 한다.
6. 원문을 보고 의미 있는 소재를 북마크와 메모로 남긴다.

**현재 구현**: 한 조건을 집계·키워드·계정 목록·게시물·CSV에 적용하며, 브랜드는 별칭 사전으로 식별한다. 이전 탐색 조건에는 키워드/브랜드/계정/SET/기간/작성자 유형/OR·AND가 들어 있다. 뒤로 돌아가 다른 가지를 탐색할 수 있다. 브랜드 목록은 자동 글로벌 브랜드 탐지가 아니라 등록한 이름과 본문이 일치한 결과다.

**판단 질문**: 브랜드가 직접 올린 글인가, 외부 계정이 언급한 것인가? 특정 제품군의 반복 메시지인가? 조회가 큰 한 건이 전체 인상을 만든 것은 아닌가?

## 두 번째 흐름: 표현에서 크리에이터, 신제품 가설로

1. `수부지`와 함께 나타나는 `탄력탱탱`을 발견한다.
2. 두 표현이 함께 나온 원문을 확인한다.
3. 해당 표현을 쓰는 작성자를 찾는다.
4. 그 계정의 관련 글만 보거나, 키워드 조건을 풀고 최근 수집한 글 전체의 다른 표현을 본다.
5. 여러 계정으로 같은 탐색을 반복하고 표현의 확산과 계정별 편향을 비교한다.
6. ‘수부지 소비자에게 어떤 보습감·마무리감·탄력 메시지를 검토할까’라는 가설을 작성한다.

**현재 구현**: 키워드 후보별 글 수/작성자 수/동일 길이 이전 기간 대비 변화, 작성자별 관련 글과 계정 전체 표현으로 이동. 단어 후보는 문장 수준의 의미 관계를 보증하지 않는다. 예컨대 ‘탄력탱탱’이 신제품 수요를 의미하는지 여부는 별도의 원문 검토와 제품 검증이 필요하다.

**확장할 기능**: 근거 구절·문장 단위 동시 등장, 제품 유형/성분/피부 고민의 정규화, 크리에이터 여러 명의 공통·고유 표현 비교, 조사 가설과 근거 콘텐츠를 함께 저장하는 리서치 노트. 이는 원본 검증 기능과 구분한 우리 확장 후보다.

## 추가 검증할 탐색 흐름

| 흐름 | 확인할 연결 | 팀이 내릴 수 있는 다음 판단 | 현재 상태 |
|---|---|---|---|
| 외부 브랜드 언급 → 새 작성자 → 최근 콘텐츠 | 기존에 모르던 인플루언서와 원문 | 레퍼런스 보관·협업 검토 | 기존 수집 자료 내 연결만 구현; 발견 수집 미연결 |
| 경쟁 브랜드 → 광고 카피 → 소셜 표현 | 광고에서 강조한 혜택이 외부 글에도 등장하는지 | 메시지 실험 가설 | 광고 수동 참고 저장만 구현; 교차 집계 미구현 |
| 제품군 → 성분 → 피부 고민 → 표현 | 같은 성분을 누구에게 어떻게 설명하는지 | 차별화 메시지와 제형 검토 | 단어 후보 탐색만 구현; 개체·문맥 분류 미구현 |
| 표현 증가 → 작성자 확산 → 원문 표본 | 여러 독립 계정에서 반복되는지 | 일시적 이슈·협찬 집중·트렌드 후보 구분 | 글/계정 수와 전기 비교 구현; 독립성·캠페인 판정 미구현 |
| 인플루언서 → 여러 브랜드 → 표현 변화 | 특정 브랜드 광고인지 평소 주제인지 | 레퍼런스 적합성 검토 | 단일 계정 탐색; 시계열 브랜드 비교 미구현 |
| 발견 → 북마크 → 팀 검토 → 실행 → 후속 관찰 | 근거에서 실제 제품·콘텐츠 실험으로 이어지는지 | 제품/메시지 가설 검증 | 개인 북마크/메모 구현; 팀 검토·실험 기록 미구현 |

## 운영할 때 남겨야 할 근거

게시물 원문·작성자·게시일·수집일, 어떤 키워드/계정에서 발견했는지, 관측한 수치와 관측 시각, 자료 범위와 누락 가능성을 함께 보존한다. 시장 전체라는 표현은 사용하지 않는다. 국가를 언어만으로 추정하지 않고, 협찬 해시태그가 없다는 이유로 일반 자발 후기라고 분류하지 않는다.

새로 발견한 작성자 수, 제품에 대한 구체적인 외부 표현, 다시 활용한 레퍼런스, 실제 검토·실험으로 이어진 근거 묶음을 운영 성과 후보로 삼는다. 자동 수집량만 늘어났다는 이유로 마케팅 역량이 개선됐다고 결론내리지 않는다.

## 수집 연결이 해결해야 할 조건

- Instagram: 등록 계정 업데이트와 미등록 계정 발견은 별도 수집 경로다. Business Discovery만으로 임의 키워드의 전역 본문 검색을 보장하지 않는다. 해시태그 검색의 권한·범위·누락·갱신 제한도 별도 확인한다.
- Meta 광고: 원본 광고 소재와 라이브러리 ID, 확인한 상태/시각을 보존한다. 접근 가능한 시장·광고 유형·수집 경로를 검증한 뒤 자동화한다. Instagram 읽기 토큰과 동일한 데이터 권한으로 취급하지 않는다.
- YouTube: [공식 search.list](https://developers.google.com/youtube/v3/docs/search/list)는 키워드 검색과 게시 기간·정렬을 제공한다. 검색 인덱스 누락/지연이 있을 수 있으며, 영상 안에서 말로 언급한 모든 브랜드를 잡는 기능과는 별개다. 원문 영상과 검색 조건을 남기는 검색 어댑터를 다음 단계로 연결한다.
